## 시간을 기다리지 않고 테스트하기

프로젝트 폴더에서 실행한다.

```sh
.venv/bin/python -m unittest discover -s tests -v
```

08:35, 09:35, 10:30 등의 시각을 테스트 데이터로 직접 전달한다.
마감 직전·정각·직후와 월 변경도 즉시 검증할 수 있다. 실제 시간을 변경하거나
매번 아침까지 기다릴 필요가 없다. 임시 DB를 사용하며 실제 Discord에 메시지를 보내지 않는다.

## 다음은 Discord 연결 시험

상시 서버가 없어도 로컬에서 봇을 실행해 Discord와 연결할 수 있다.
호스팅 서버는 컴퓨터가 꺼져도 계속 운영하기 위해 필요하다.

1. 시험용 Discord 서버와 **별도 봇 계정/토큰**을 준비한다.
2. 기상 포럼, 모닝 음성 채널, 휴무 안내 채널을 만든다.
3. `.env`의 서버·채널 ID, 토큰을 설정한다. 시험용 `DATABASE_PATH`를 지정한다.
4. 봇을 실행하고 명령 표시, 관리자 권한, 휴무 신청·취소·승인 흐름을 확인한다.
5. 실제 카메라·화면 공유 수집, 정시 실행, 댓글 전송까지 연결 시험한다.

**현재 일반 실행은 실제 운영 시간표를 따른다.** 위 자동 테스트가 가상 시간을 사용하는 것과 달리,
Discord에서 전체 일정을 수분 안에 실행하는 시험 모드는 아직 없다.
아침까지 기다리지 않고 Discord 전체 흐름을 보려면, 다음 개발 단계로
**시험 서버·별도 DB에서만 실행되는 수동 시나리오 도구**를 추가한다.
운영 마감을 느슨하게 바꾸거나 실제 서버의 시간을 바꾸는 방식은 사용하지 않는다.

Discord 연결 시험을 통과한 뒤 서버를 선택하고, 실제 시간표로 하루 시험 운영하여
연결 유지·정시 기록·재시작 복구를 최종 확인한다.

설치와 배포 설정은 [개발 문서](DEVELOPMENT.md), 참여 규칙은 [README](../README.md)를 참고한다.
