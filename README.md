# ☀️ 맥모닝 스터디 — 맥집사

맥집사는 Discord에서 **휴무 신청, 출석 확인, 벌점 관리**를 도와주는 스터디 봇입니다.

**평일에 운영하며, 토요일·일요일·한국 공휴일에는 출결을 관리하지 않습니다.** 모든 시간은 한국 시간입니다. 목표·성과 관리는 현재 운영 범위에 포함하지 않습니다.

## 하루 참여 방법

1. **당일 기상 인증 게시글에 첫 댓글**을 남깁니다.
2. 정해진 시각에 **모닝 (8:30-10:30)** 음성 채널에서 **카메라 또는 화면 공유**를 켭니다.
3. **10:30에 같은 기상 인증 게시글의 댓글로 출결 결과와 월 누적 벌점**을 확인합니다.

기상 인증만 하거나 음성 채널에 입장만 해서는 정상 출석이 되지 않습니다. 정해진 시각의 카메라·화면 공유 상태를 확인합니다.

## 자동 운영 시간표

| 언제 | 맥집사가 하는 일 |
|---|---|
| 평일 06:00 | 당일 기상 인증 게시글 생성 |
| 평일 08:35 | 일반 참여자·일찍 퇴근 반휴자의 영상 참여 확인 |
| 평일 09:35 | 늦게 출근 반휴자의 영상 참여 확인 |
| 평일 10:30 | 휴무와 참여 기록을 대조하고, **당일 기상 인증 게시글에 결과 댓글 작성** |
| 토요일 10:00 | 다음 주 월~금 휴무 신청 안내 게시글 생성 |

평일이라도 한국 공휴일에는 위 출결 일정을 실행하지 않습니다. 토요일 휴무 안내는 별도로 올라옵니다.

## 기상 인증과 출결

당일 기상 인증 게시글에 남긴 **첫 유효 댓글**로 기상 시각을 판단합니다. 텍스트 또는 첨부파일이 있는 댓글을 인정하며, 공백만 있는 댓글은 제외합니다. 추가 댓글을 남겨도 최초 인증은 바뀌지 않습니다.

### 일반 참여자·일찍 퇴근 반휴자

| 첫 기상 인증 | 08:35 카메라 또는 화면 공유 | 최종 결과 | 벌점 |
|---|---|---|---|
| 08:00까지 | 켜짐 | 출석 | 0점 |
| 08:01~08:30 | 켜짐 | 지각 | +1점 |
| 08:31 이후 또는 인증 없음 | 관계없음 | 결석 | +2점 |
| 08:30까지 인증 | 꺼짐 또는 음성 채널 미참여 | 결석 | +2점 |

**08:00까지는 08:00:59까지, 08:30까지는 08:30:59까지를 포함합니다.** 일반 참여자는 09:35에 참여해도 08:35 미참여를 대신할 수 없습니다.

### 늦게 출근 반휴자

아래 두 조건을 **모두** 충족해야 출석입니다.

- **09:30 이전**에 기상 인증 댓글 작성 — 09:30:00부터는 인정되지 않습니다.
- **09:35**에 모닝 채널에서 카메라 또는 화면 공유 참여

모두 충족하면 **출석·0점**, 하나라도 충족하지 못하면 **결석·+2점**입니다. 별도 지각 구간은 없습니다.

## 휴무 신청과 취소

토요일 오전 10시에 다음 주 휴무 안내가 올라옵니다. **가장 최근 안내 글에 명시된 월~금 기간에만 신청·취소할 수 있습니다.** 새 안내 글이 올라오면 신청·취소 가능 기간도 새 기간으로 바뀝니다. 그 이후 주의 휴무를 미리 신청할 수는 없습니다.

| 휴무 종류 | 사용 횟수 | 출결 적용 |
|---|---|---|
| 전일 휴무 (`종일`) | 주 1회 | 당일 출결 면제·벌점 없음 |
| 반휴 — 늦게 출근 (`반휴(늦게 참여)`) | 주간 반휴 합산 2회 | 09:30 이전 인증 + 09:35 영상 참여 |
| 반휴 — 일찍 퇴근 (`반휴(일찍 퇴장)`) | 주간 반휴 합산 2회 | 일반 기상 인증 기준 + 08:35 영상 참여 |
| 기타 휴무 | 제한 없음 | **증빙 제출 + 관리자 승인** 시 전일 휴무처럼 적용 |

한 주는 월요일~일요일입니다. **전일 1회 또는 반휴 2회 중 하나**를 사용할 수 있습니다.

- 가능: 전일 1회 / 반휴 1회 / 반휴 2회
- 불가능: 전일 2회 / 전일 1회 + 반휴 1회 / 반휴 3회
- 기타 휴무는 이 한도에 포함하지 않습니다.
- 주말·공휴일에는 휴무를 신청할 필요가 없습니다.

### 마감 시각

| 항목 | 언제까지 인정되나요? |
|---|---|
| 당일 휴무 신청·취소 | **08:30까지** — 08:31:00부터 불가 |
| 기타 휴무 관리자 승인 | **10:00까지** — 10:01:00부터 불가 |

기타 휴무는 **신청 마감과 승인 마감을 모두 지켜야** 인정됩니다. 대기·반려·취소 상태의 신청은 출결 면제에 반영되지 않습니다.

### 휴무 명령어

| 명령어 | 용도 |
|---|---|
| `/휴무신청` | 유형 선택 → 날짜 목록에서 선택 → 신청 버튼. 기타 휴무는 명령에 증빙 첨부 |
| `/휴무취소` | 현재 신청 기간의 내 휴무 선택 → 취소 버튼 |
| `/내휴무` | 최신 주간 안내 기간의 내 신청 내역·상태만 확인 |

## 벌점과 멤버 관리

| 상황 | 벌점 |
|---|---|
| 출석·인정된 전일/기타 휴무 | 0점 |
| 지각 | +1점 |
| 결석 | +2점 |

- **활성 멤버**만 정규 출결·벌점 관리 대상입니다.
- **비활성 멤버**는 자율 참여합니다. 봇에서 `휴면`·`강퇴`로 표시된 멤버도 관리 대상에서 제외됩니다.
- 벌점은 **매달 1일 0점부터 새로 집계**합니다. 지난달 기록은 보관됩니다.
- 현재 월 누적 **6점 이상이면 퇴출 대상으로 표시**합니다. 실제 퇴출은 관리자가 처리합니다.
- `/출결확인`으로 날짜별 출결과 해당 월 벌점을, `/벌점확인`으로 현재 월 벌점을 확인합니다.

## 봇이 확인하지 못한 날

장애로 영상 기록이 누락되거나 기상 인증 기록을 충분히 확인할 수 없으면 **‘확인 필요’로 표시하고 자동 벌점을 부과하지 않습니다.** 관리자가 확인한 뒤 정정합니다.

관리자는 `/휴무관리` 한 화면에서 신청자·날짜·증빙 링크를 확인하고 **승인·반려 버튼**으로 처리할 수 있습니다. 여러 신청은 **이전·다음**으로 넘기고 **새로고침**으로 최신 목록을 확인합니다. 신청 ID를 입력할 필요는 없습니다. 화면은 관리자에게만 보이며 10분 후 만료됩니다. 출결이 잘못되었거나 확인이 필요하면 `/출결정정`으로 사유와 함께 수정합니다.

정정 이후의 최신 결과는 `/출결확인`에서 확인할 수 있습니다. 이미 작성된 결과 댓글은 자동 갱신되지 않습니다.
